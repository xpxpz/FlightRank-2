# FlightRank 排序实验报告

结果日期：2026-11-24。比赛：[Aeroclub RecSys 2025](https://www.kaggle.com/competitions/aeroclub-recsys-2025)；参考 [公开 baseline](https://www.kaggle.com/code/ka1242/xgboost-ranker-with-polars) 与 [第二名代码](https://github.com/Rajneesh-Tiwari/FlightRank-2025-Aeroclub-RecSys-Cup)。本报告数字均为本次本地验证，非本人比赛排名或私榜成绩。

## 数据与评价

训练集 18,145,372 行、105,539 个完整搜索会话，测试集 6,897,776 行、45,231 个会话；训练会话均有且仅有一个正例。官方 HitRate@3 对候选数大于 10 的会话，计算正例进入得分前三的比例，按会话平均；训练使用所有会话。数据哈希及核查见 [数据校验记录](数据校验记录.md)。划分和抽样均保持会话完整。输出排序应在每个会话内无重复且保留原测试行顺序。

## 特征消融

以标签隔离 NB0036 第 0 折完整模型为参照；每项独立重新训练，仅比较相同验证会话。完整模型 274 个输入；三类分别移除 41、163、80 个列。类别按列名和聚合配置定义，可能重叠，移除范围见 `results/models/nb_nested_*/fold_0/features.json`。

| 移除类别 | HR@3 | 相对完整模型 | 配对 bootstrap 95% 区间 |
|---|---:|---:|---|
| 价格 | 0.649749 | +0.008254 | [0.001896, 0.014278] |
| 便利性 | 0.563302 | -0.078193 | [-0.086113, -0.070270] |
| 用户或企业行为 | 0.628221 | -0.013274 | [-0.020078, -0.006578] |

该单折中移除价格类特征后略有提升，移除便利性和行为类特征后下降。宽范围分组、组间重叠及特征替代作用使其不能解释为单列的因果贡献；多组对照和单次划分也限制外推。

## 模型与实现差异

baseline 使用 1000 轮；NB0036 使用 GroupKFold 10 折、3500 轮、每样本 8 对，均使用 `rank:pairwise`、`ndcg@3`、深度 10、min_child_weight 10、subsample/colsample 0.8、lambda 10、学习率 0.05、seed 42。原 baseline 在行 16487352 切分：边界未切开会话，但会话请求时间有 32,244 次倒退，故不是严格按时间切分。NB0036 额外构造会话内价格与航程竞争、转机、用户、企业、路线等统计。原始第 0 折实际输入 baseline 115 列、NB0036 277 列；40 列名称相同，但不保证数值或语义相同。逐列清单见 [实际特征清单](实际特征清单.md)，代码版本与参数见 [代码与泄漏审查](代码与泄漏审查.md)。

为适应资源和版本，运行入口限制 12 线程、显式按会话排序、使用 float32 矩阵、会话计数分折、窄表聚合与向量化时长解析；作者原始 notebook 保存在 `references/`。完整数据的不同时长值逐项验证与原解析一致；合成和真实 500 会话样本上，窄表及分折优化的验证 ID 和 20 轮预测一致，不能据此声称全量逐值等价。原始模式用于复现，嵌套聚合模式用于隔离对照。

## 泄漏与限制

baseline 原版用全量标签计算航司均值后才切分；NB0036 原版外层训练行的跨折标签聚合可能包含外层验证标签。嵌套模式在外层训练内再做 5 折交叉拟合，外层验证只使用外层训练标签，修正了上述路径。改变外层验证标签后合成数据预测不变，仅验证该路径。两种方案的无标签跨会话统计仍可能使用验证或测试期信息；时间划分的训练内部交叉拟合也不是按每个请求时点截断的历史窗口，所以时间实验仍不是严格上线模拟。原十折混用 CPU 与 PPU；2,000 会话小样本两设备预测相关约 0.969，结果并不逐值一致。作者私榜分数仅供参考。

## 资源、日志与产物

服务器为 16 核容器、约 174 GiB 内存和 96 GiB PPU-ZW810。独立环境基于 PPU SDK 12.6 自编译 XGBoost 2.1.4，`quantile.h` 做相等运算兼容补丁；官方 wheel 在该环境回退 CPU。自编译运行出现 `empty kernel launch` 提示，不能宣称与官方构建完全等价。库哈希、完整参数与环境见各 `result.json`。日志记录设备 `cuda:0`，采样曾观察 PPU 100% 利用率。容器 cgroup 达 160 GiB 时保护性停止；全部最终队列阶段退出码均为 0。

原固定划分 baseline 脚本记录 371.7 秒、峰值 RSS 83.6 GiB；原标签聚合 GroupKFold 第 0 折记录 2129.5 秒、峰值 RSS 76.4 GiB（运行环境与设备不同，不宜直接作速度对比）。标签隔离 baseline 单折脚本记录 375 秒、进程峰值 RSS 82.4 GiB；完整 NB0036 单折总耗时约 142 分钟、峰值 RSS 106.0 GiB；时间验证 NB0036 总耗时约 140 分钟、峰值 RSS 106.4 GiB。RSS 不等同于包含缓存的容器总内存。训练曲线为 NDCG@3，并非 loss，见 [训练曲线](../results/figures/ndcg_curves.png)。标签隔离 NB0036 的第 3499 轮训练 NDCG@3 为 0.99164、验证为 0.60311，二者存在明显差距；在记录的每 50 轮采样点中验证指标仍在末轮达到最高值，不能仅凭差距判断提前停止会提升最终 HR@3。

模型、预测及完整资源日志保存在服务器 `/workspace/flightrank/runs/continued_20261122`、`/workspace/flightrank/runs/ppu_resume_20261123` 和 `/workspace/flightrank/runs/isolated_retry`；原工作区 `results/final/` 保存汇总、特征列表、阶段控制台和运行元信息；模型和预测备份在 `results/server_backup/`，以 `SHA256SUMS` 校验。服务器文件会随服务器生命周期变化。后台状态 `isolated_retry/status.txt` 最后一行为 `COMPLETE all`。已核对 102 个模型、预测和结果文件的 SHA-256；提交文件 45,231 个会话均为 1 至 N 排名，6,897,776 行的 Id 和会话顺序与测试集一致。PPU 二进制另已核对其记录哈希。

## 简历描述（按实际工作表述）

基于 FlightRank 航班候选数据复现 XGBoost 排序单模型及公开基线，完成按搜索会话分组的十折训练、标签聚合泄漏排查、嵌套交叉拟合对照和时间划分验证；在同一时间验证集上，本地 HitRate@3 从 0.5170 提升至 0.5485。设计价格、便利性和用户/企业行为特征消融，并针对国产 PPU 适配 XGBoost、优化全量特征处理内存，记录模型、预测与资源日志。结果为本地实验，不代表比赛成绩。
